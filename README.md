# 정철호 | 보안 인프라 엔지니어 포트폴리오

> 엔드포인트 위협 탐지부터 OSINT 인텔리전스 수집까지, 보안 시스템의 전 레이어를 직접 설계하고 구현한 경험을 보유한 보안 인프라 엔지니어 정철호입니다.

- **Core:** 보안 인프라 구축, 위협 식별 엔진 엔지니어링, 보안 자동화 모듈 설계
- **Approach:** 현장의 보안 공백을 파악하고, 스크립트와 오픈소스를 결합하여 실제 작동하는 '방어 시스템'으로 구현합니다.

## 프로젝트 상세

### 1. [Semi 1] OSINT 기반 위협 인텔리전스 시스템

기업 이메일을 입력받아 텔레그램 해커 채널 17개, 다크웹 미러링 사이트 4개, Tor 기반 실제 다크웹 3개를 4개 레이어로 병렬 탐색하여 임직원 자격증명 유출, 기밀 자산 노출, 랜섬웨어 피해, 프로젝트 소스코드 유출 여부를 실시간으로 진단하는 인텔리전스 모듈

**담당 파트:** 비동기 B2B 크롤러 모듈 일체, 검색 로직 및 데이터 표준화 아키텍처

- **비동기 병렬 수집 엔진 구축:** `aiohttp`와 `asyncio.gather()`로 텔레그램 채널 17개와 미러링 사이트 4개를 동시 병렬 탐색. 멀티스레딩 대비 시스템 자원 소비를 최소화
- **4대 검색 레이어 구현:** 이메일(자격증명) → 도메인(자산 노출) → 회사명(랜섬웨어) → 프로젝트 키워드(소스코드 유출) 순으로 탐색하는 계층형 수집 로직 설계
- **Gemini AI 경쟁사 분석 연동:** `gemini-2.5-flash`가 기업명을 분석하여 경쟁사 3개를 자동 산출, ransomwatch GitHub 공개 DB와 대조하여 랜섬웨어 피해 현황 파악
- **데이터 표준화 아키텍처:** 텔레그램·미러링·Tor 다크웹 등 이종 소스 수집 데이터를 단일 JSON 스키마(`id`, `keyword_type`, `source_id`, `original_link`, `raw_text`, `leak_date`)로 정규화하여 백엔드 직접 적재 가능하도록 인터페이스 통일
- **스팸 필터 및 유효성 검증:** 20자 미만·스팸 키워드 포함 메시지 1차 차단 후 실제 위협 키워드 포함 여부를 2단계 검증하는 노이즈 제거 로직 구현

### 2. [Semi 2] 샌드박스 구축 및 모바일 앱 분석 자동화 시스템

정적 분석 데이터(CVE, MITRE ATT&CK)를 기반으로 Genymotion 가상 격리 환경을 구동하고 Frida로 메모리를 계측하며 Android logcat 로그를 실시간 추출·분석하여 악성 행위를 자동 판별하는 보안 시스템

**담당 파트:** 동적 분석 파이프라인 아키텍처 설계 및 위험 식별 엔진 리드 개발 (8개 API 파이프라인)

- **분석 모드 동적 분기 설계:** 정적 분석 결과의 위협 태그 유무를 판별하여 선별 추적하는 `speedy` 모드와 제로 트러스트 전수 조사하는 `exact` 모드로 분석 아키텍처를 동적으로 분리
- **샌드박스 구동 자동화:** Genymotion 에뮬레이터 부팅 검증(`sys.boot_completed`) → APK 설치(최대 3회 재시도) → Frida `device.spawn()` → `agent.js` 로드까지 12단계 파이프라인을 단일 함수로 자동화
- **안티분석 탐지 방어 로직:** 앱이 분석 환경을 탐지해 세션을 강제 종료하는 경우(`Terminated`, `Detach` 등 6개 키워드) 예외를 캐치하여 MITRE ATT&CK `T1622` 태그를 강제 부여하고 위험 파일로 판정하는 방어 로직 구현
- **정규식 기반 위험 식별 엔진 독자 구현:** `threat_signature.py`의 카테고리별 보안 시그니처(SMS 탈취, 금융 정보 탈취, 권한 상승 등) 정규식 딕셔너리와 raw 로그를 실시간 매핑하는 핵심 탐지 엔진 설계
- **크로스 플랫폼 ADB 경로 탐색:** `shutil.which()` → macOS SDK 경로 → Windows SDK 경로 순으로 탐색하는 OS 독립 로직으로 어느 환경에서도 분석 환경이 정상 구동되도록 보장

### 3. [Semi 3] 서비스 포트 스캐너 & 취약점 진단 시스템

열린 포트 탐색, 서비스 식별, Nuclei CVE 매핑, Shodan/VirusTotal OSINT 조회, EPSS 공격 발생 확률 연동, Wappalyzer 웹 기술스택 탐지, Gemini AI 보안 권고안 생성까지 하나의 파이프라인으로 통합한 인프라 자산 풀스택 진단 시스템

**담당 파트:** 7개 클래스 기반 전체 스캐너 모듈 설계 및 구현 일체

- **하이브리드 스캔 엔진:** Nmap SYN 스캔(`-sS -Pn`)을 메인으로, 실패 시 `asyncio.open_connection()` TCP Connect 스캔으로 자동 전환하는 이중 폴백 구조 설계
- **psutil 커널 프로세스 역추적:** 배너 은닉으로 Nmap이 서비스를 식별하지 못하는 경우 `psutil.net_connections()`으로 해당 포트를 점유 중인 실제 PID, 실행 파일 경로, 서비스명을 직접 파싱하는 하이브리드 식별 엔진 구현
- **Nuclei CVE 매핑:** `asyncio.create_subprocess_exec()`으로 Nuclei를 비동기 실행하여 CVE ID, 심각도, 설명, 참조 링크를 구조화된 JSON으로 수집
- **EPSS 기반 위험도 가중 산출:** CVSS 기본 점수와 `api.first.org` EPSS 실제 공격 발생 확률을 가중 평균(`CVSS × 0.6 + EPSS × 0.4`)하여 이론적 위험도와 실제 공격 가능성을 분리한 Risk Score 산출
- **Shodan/VirusTotal OSINT 통합:** 외부 공격자 시점의 IP 노출 이력(Shodan)과 엔진별 악성 판정 수(VirusTotal API v3)를 병렬 조회하여 내부 스캔만으로는 파악 불가한 외부 위협 가시성 확보
- **Gemini AI 보안 권고안 자동 생성:** CVE 탐지 시 포트·서비스·취약점 정보를 CERT 전문가 역할 프롬프트로 구성하여 실무자가 즉시 사용 가능한 CLI 명령어 포함 한국어 보안 권고안 생성
- **패킷 캡처 및 증거 수집:** Scapy `AsyncSniffer`로 활성 포트 트래픽을 실시간 덤프하고 타임스탬프 기반 PCAP 파일로 자동 저장하여 침해사고 대응 시 증거 보존 요건 충족

### 4. [Final] Q-Sight: SaaS 기반 EDR 솔루션

Windows 엔드포인트에서 다운로드되는 파일을 `FileSystemWatcher`로 실시간 감시하고 VirusTotal SHA-256 정적 분석으로 위협 여부를 판별하는 SaaS 형태의 EDR 보안 솔루션

**담당 파트:** PM / API 스펙 및 DB 스키마 설계 / 브랜치 전략 수립 / 코드 통합

- **API 스펙 및 DB 스키마 사전 설계:** 팀 개발 착수 전 API 명세와 PostgreSQL 스키마를 사전 정의하여 백엔드·프론트엔드·분석 파트 간 연동 오류와 소통 병목을 최소화
- **브랜치 전략 수립 및 크로스팀 코드 리뷰:** Git 브랜치 전략(feature / develop / main)을 수립하고 C#·Python 이기종 기술 스택 간 크로스팀 리뷰를 주도하여 통합 충돌 사전 방지
- **공백 리스크 관리 및 코드 통합:** 마감 직전 팀원 공백 발생 시 해당 파트 코드를 밤새 파악하여 유기적으로 결합, 솔루션 완성도를 유지한 채 발표와 시스템 구축 완수

## 엔지니어로서의 차별점

**1. 보안 시스템 전 레이어를 직접 구현하는 시스템 이해도**

OSINT 수집 크롤러, APK 동적 분석 샌드박스, 네트워크 취약점 진단 엔진, EDR 솔루션까지 보안 시스템의 수집·분석·탐지·대응 레이어 전반을 직접 설계하고 구현했습니다. 단순한 도구 활용을 넘어 비동기 아키텍처, 정규식 탐지 엔진, AI 연동 파이프라인 등 백엔드 메커니즘을 깊이 있게 이해하고 있습니다.

**2. 현장 중심의 문제 해결력과 조율 능력**

다양한 현장 환경에서 체득한 실행력과 PM 경험을 바탕으로, 협업 시 발생하는 기술적 병목과 인력 공백 리스크를 유연하고 책임감 있게 해결합니다.
