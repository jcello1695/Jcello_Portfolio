Core: 보안 인프라 구축, 위협 식별 엔진 엔지니어링, 보안 자동화 모듈 설계
Approach: 현장의 보안 공백을 파악하고, 스크립트와 오픈소스를 결합하여 실제 작동하는 '방어 시스템'으로 구현합니다.

부트캠프 프로젝트 상세
1. [Semi 1] OSINT 기반 위협 인텔리전스 시스템
외부 채널에 노출된 보안 위협 정보를 실시간으로 수집·구조화하여 선제적 방어 체계를 구축하는 플랫폼
담당 파트: 수집 모듈 일체, 검색 로직 및 데이터 표준화

비동기 B2B 크롤러 시스템 구축: OSINT 출처로부터 악성 IP·취약점 데이터를 유실 없이 수집하기 위해 비동기 수집 프로세스가 적용된 크롤러 모듈 일체를 전담 개발
데이터 포맷 표준화: 이종의 위협 데이터를 보안 시스템이 즉시 분석할 수 있도록 통일된 규격으로 정제하는 표준화 아키텍처 구현
검색 및 연계 로직 구현: 인프라 관리자가 최신 위협 정보를 신속하게 조회하고 방화벽 차단 정책에 연계할 수 있도록 고속 검색 로직 설계


2. [Semi 2] 샌드박스 구축 및 모바일 앱 분석 자동화 시스템
모바일 애플리케이션(APK)의 위협을 안전하게 격리된 환경에서 정적·동적 분석하는 자동화 시스템
담당 파트: 동적 분석 파이프라인 아키텍처 설계 및 위험 식별 엔진 리드 개발

에뮬레이터 기반 샌드박스 인프라 구축: Genymotion 에뮬레이터를 활용해 악성 앱이 실제 시스템에 영향을 주지 않는 격리된 가상 분석 환경 구축
동적 로그 산출 및 자동화: logcat과 연동하여 가상 환경 내 앱 실행 행위를 실시간으로 추출하는 파이프라인 엔지니어링
위험 식별 엔진 개발: raw 로그를 정제·분석하여 악성 행위와 보안 취약점을 자동 판별·점수화하는 핵심 로직 독자 리드 개발


3. [Semi 3] 서비스 포트 스캐너 & 취약점 진단 시스템
네트워크 인프라의 보안 공백(불필요하게 열린 포트·서비스)을 탐지하는 자산 진단 시스템
담당 파트: 고속 비동기 스캐너 모듈 구현 일체 및 취약점 진단 파이프라인 구축

비동기 소켓 기반 고속 포트 탐색: asyncio 기반 TCP Connect Scan으로 대규모 자산 진단 시 속도 병목 문제 해소
하이브리드 서비스 역추적 엔진: Nmap SYN 스캔과 psutil 커널 프로세스 백트래킹을 결합해 배너 은닉 환경에서도 실제 프로세스를 정확하게 식별
패킷 캡처 및 증거 수집: Scapy AsyncSniffer로 트래픽을 실시간 덤프하고 침해사고 대응 시 증거 보존 요건을 충족하는 PCAP 형태로 자동 저장


4. [Final] Q-Sight: SaaS 기반 EDR 솔루션
Windows 엔드포인트의 위협을 실시간으로 탐지·대응·분석하는 SaaS 형태의 EDR 보안 시스템
담당 파트: PM / API 스펙 설계 / 브랜치 전략 수립 / 코드 통합

프로젝트 총괄 (PM): 백엔드·프론트엔드·분석 파트 간 개발 속도와 소통 병목을 해결하며 마일스톤 유지
API 스펙 및 DB 스키마 설계: 팀 전체 개발 기반이 되는 API 명세와 스키마를 사전에 설계하여 파트 간 연동 오류를 최소화
브랜치 전략 수립 및 코드 리뷰: Git 브랜치 전략을 수립하고 크로스팀 코드 리뷰를 주도하여 통합 충돌을 사전 방지
코드 통합 및 공백 리스크 관리: 마감 직전 팀원 공백 발생 시 해당 파트 코드를 밤새 파악하여 솔루션 완성도를 유지한 채 발표 완수
