# 가시성 확보를 위한 비동기 서비스 포트 스캐너 & 취약점 진단 시스템 (Semi-Project 3차)

> **담당 파트:** 고속 비동기 스캐너 모듈 구현 일체 및 네트워크 인프라 취약점 진단 파이프라인 구축 (`deepguard_portscanner.py`)

본 모듈은 네트워크 인프라의 최전방 공격 표면을 식별하기 위해 열린 포트 탐색, 구동 서비스 배너 파싱, 그리고 CVE/OSINT 위협 데이터를 매핑하여 실시간으로 인프라 위험도를 스코어링하는 **인프라 자산 진단 시스템**입니다.

---

##  핵심 파이프라인 및 구현 명세

### 1. 비동기 소켓 기반 고속 포트 탐색 (`scan_port_setting`)
* **`asyncio.open_connection` 활용:** 대규모 자산 진단 시 발생하는 속도 저하 문제를 극복하기 위해, 멀티스레딩 방식보다 가볍고 빠른 비동기 소켓 연결(TCP Connect Scan) 방식을 직접 구현했습니다.
* **타임아웃 핸들링:** 각 포트별 대기 시간을 `timeout=1.0`초로 바인딩하여 시스템 자원(소켓 바인딩 개수) 유실을 방지하고 스캔 효율성을 극대화했습니다.

### 2. 하이브리드 서비스 및 프로세스 역추적 엔진 (`process_target_port`)
* **Nmap SYN 은닉 스캔 (`python-nmap`):** 호스트의 보안 정책(방화벽 등)을 우회하고 정밀하게 배너 정보를 수집하기 위해 Nmap의 SYN 스캔(`-sS -Pn`) 기법을 스캐너 엔진에 이식했습니다.
* **로컬 커널 프로세스 백트래킹 (`psutil` 연동):** 방화벽이나 배너 은닉 설정으로 인해 Nmap이 구동 서비스를 식별하지 못하는 상황(`unknown`)이 발생할 경우를 대비한 예외 로직을 설계했습니다.
* 관리자 권한 환경에서 시스템 커널의 네트워크 커넥션을 직접 역추적하는 `psutil.net_connections()`를 바인딩하여, 해당 포트를 점유하고 활성화 중인 **실제 프로세스 PID, 실행 파일 경로(`exe`), 실제 서비스 명**을 명확하게 파싱해 내는 하이브리드 엔진을 완성했습니다.

### 3. 패킷 캡처 인프라 및 CERT 증거 수집 체계 (`EvidenceCollector`)
* **비동기 패킷 스니핑 (`scapy.all.AsyncSniffer`):** 특정 포트의 활성화 상태가 확인되는 즉시 백그라운드 스레드에서 해당 포트의 아웃바운드/인바운드 트래픽 흐름을 실시간으로 덤프하는 스니퍼 인프라를 구축했습니다.
* **디지털 포렌식 무결성 확보:** 분석이 종료되면 수집된 세션 패킷을 타임스탬프 기반의 표준 네트워크 패킷 파일인 **PCAP 파일(`traffic_*.pcap`)**로 자동 빌드 및 저장하여, 향후 침해사고 대응팀(CERT)이 정밀 분석을 수행할 수 있도록 기술적 증거 수집 체계를 수립했습니다.
