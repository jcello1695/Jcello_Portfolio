# MobSF 연동 안드로이드 동적 분석 및 위험 식별 엔진

> **본인 담당 파트:** 동적 분석 파이프라인 아키텍처 설계 및 위험 식별/정규식 필터링 엔진 리드 개발

## 시스템 아키텍처 및 핵심 구현 역량

정적 분석 데이터(CVE, MITRE ATT&CK 기술)를 기반으로 가상 격리 환경을 구동하고, 안드로이드 시스템 로그를 실시간으로 추출·추적하여 악성 행위를 자동 판별하는 보안 시스템입니다. 

철호님이 독자적으로 구조화하고 구현한 **8개의 핵심 API 파이프라인**을 기반으로 작동합니다.

---

## 핵심 모듈 및 API 명세

### 1. 인프라 환경 구성 및 데이터 수집 파트
* **API 1. 크로스 플랫폼 호환 ADB 경로 자동 탐색 (`get_adb_path`)**
  - 분석 환경의 OS 독립성을 보장하기 위해 시스템 환경 변수를 1차 검증하고, Windows 및 macOS의 Android SDK 표준 설치 경로를 계층적으로 추적하여 `adb` 바이너리 경로를 무결하게 확보하는 예외 처리 로직을 구현했습니다.
* **API 2. 정적 분석 데이터 수신 및 바인딩 (`receive_static_result`)**
  - 파이프라인 전 단계에서 산출된 정적 분석 인텔리전스 결과물(`evidence.json`, `interpretation.json`)을 분석 엔진 내부 딕셔너리 구조로 안전하게 로드 및 매핑하는 인터페이스를 구축했습니다.
* **API 3. 위협 식별 기반 분석 모드 설정 (`parse_static_result`)**
  - 정적 분석에서 식별된 위험 스코어 및 크리티컬 위협 태그의 유무를 판별하여, 선별된 행위만 추적하는 **고속 모드(speedy)**와 제로 트러스트 관점에서 전수 조사를 실행하는 **정밀 모드(exact)**로 분석 아키텍처를 동적 분리했습니다.

### 2. 가상화 샌드박스 제어 및 메모리 분석 파트
* **API 4. APK 패키지 명 실시간 추출 (`get_package_name`)**
  - 안드로이드 자산 도구인 `aapt` 명령어를 파이썬 내부 서브프로세스(`subprocess.Popen`)로 제어하여, 분석 대상 악성 파일의 고유 패키지 네임과 메인 액티비티를 동적으로 파싱하는 모듈을 개발했습니다.
* **API 5. 샌드박스 구동 및 Frida 에이션트 바인딩 (`dynamic_environment`)**
  - Genymotion 가상화 에뮬레이터의 커널 부팅 완료 상태(`sys.boot_completed`)를 백그라운드에서 검증 후 안전하게 타겟 앱을 인스톨 및 실행했습니다.
  - Frida 인프라와 연동하여 메모리 내 코드를 추적하고 DEX 추출 프로세스를 자동화했으며, 악성 앱이 분석 환경을 탐지해 강제 종료(`Terminated`)되거나 세션을 해제(`Detach`)할 경우 이를 예외 처리하여 위험 등급을 강제 부여(`T1622`)하는 방어 로직을 구현했습니다.

### 3. 실시간 로그 파싱 및 위협 탐지 파트
* **API 6. Logcat 기반 시스템 커널 로그 추출 (`extract_logcat`)**
  - 가상 디바이스의 특정 패키지 프로세스 런타임에서 발생하는 프레임워크 및 리눅스 커널 레벨의 활동을 Android `logcat` 파이프라인과 버퍼 스트림으로 결합하여, 유실 없이 실시간으로 수집 가공하는 인터페이스를 엔지니어링했습니다.
* **API 7. 표준 정규식 기반 위험 식별 엔진 (`regex_filtering`)**
  - 수집된 대용량 시스템 raw 로그에서 불필요한 노이즈를 스크리닝하고, `threat_signature.py`에 정의된 보안 시그니처(SMS 무단 탈취, 금융 정보 탈취 메커니즘, 기기 권한 상승 등) 정규식 딕셔너리와 실시간 매핑하는 핵심 식별 코어 엔진을 독자 구현했습니다.
* **API 8. 위협 스코어링 및 표준 가시성 리포트 반환 (`result_json`)**
  - 탐지된 위협 시그니처의 가중치를 정량적으로 합산하여 인프라 위험도 점수(Risk Score)를 산출하고, 침해사고 분석가나 관제 엔지니어가 즉각 인프라 정책에 반영할 수 있도록 정형화된 표준 가시성 JSON 리포트를 최종 반환 및 저장하도록 구성했습니다.
